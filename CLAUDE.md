# Instruções para o Claude neste repositório

## Ideias para o LinkedIn
Quando, numa conversa, surgir um assunto, aprendizado, evento, leitura ou opinião
que possa virar post de LinkedIn (tema principal: inovação e tecnologia),
ofereça anotar em `linkedin/contexto/ideias.md` — uma linha por ideia, com a
data no formato `AAAA-MM-DD — resumo`. Com o "sim", adicione, faça commit e push.
Não anote nada pessoal ou sensível sem confirmação explícita.
